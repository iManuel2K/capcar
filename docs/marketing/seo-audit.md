# CapCar organic discovery audit

Audited 21–22 October 2026. Production baseline: https://capcar.dev. Changes verified against a local production build; repository changes are not evidence that production has updated. Goal: relevant owners completing a useful first action, rather than page count, domain scores or launch votes.

## Crawlability and indexing results: initial baseline

- Sitemap: 113 unique URLs = 13 route families × (unprefixed + five locales) + five journal indexes + 30 translated articles. Every sitemap URL returned HTTP 200 in both complete HTTP crawls. Each had a description, one canonical matching its URL, and six hreflang entries: the five languages and `x-default`. Canonical targets were indexable in the sampled responses. Existing sitemap dates were retained; no fake freshness dates were introduced.
- Public route families: `/`, `/connected-parts`, `/imprint`, `/movie-cars`, `/parts-search`, `/platform`, `/privacy`, `/roadbook`, `/roadmap`, `/sound-studio`, `/specialists`, `/studio`, `/terms`. Each also exists under every locale prefix. Journal indexes exist only at `/{locale}/journal`.
- Articles in every locale: `bmw-wochenendprojekt-planen`, `bmw-wartung-ohne-garage`, `bmw-diy-wartung-dokumentieren`, `ruesselsheim-rheingau-tagesausflug`, `build-plan-first-job`, `guide-to-vehicle-history`. Existing German slugs in other languages are not inherently an SEO defect; keep their working URLs.
- `robots.txt` returned 200, allows public pages and references the correct sitemap. Private/account/API/passport paths are excluded. Robots exclusions do not provide authentication. Existing account boundaries remain intact.
- `/login` has `noindex, follow`; `/ai` and `/system` have `noindex, nofollow`, and are absent from the sitemap. `/journal` returns 307 to `/en/journal` without a locale preference. This selector redirect is intentionally temporary because preferences can vary.
- `/not-a-real-page`, `/de/not-a-real-page`, and `/de/journal/not-a-real-article` returned 404. `/de/studio/` returns 308 to `/de/studio`. HTTP root and HTTPS `www` root each return 301 directly to `https://capcar.dev/`.
- `/de/studio` and `/de/roadbook` still served German when sent conflicting Japanese `Accept-Language` and an Albanian locale cookie. This tests explicit URL precedence, not every cache/cookie combination.
- Existing unprefixed and `/en` English duplicates are self-canonical and included in the established fallback strategy. This is a consolidation opportunity, not proof of an indexing failure. Preserve routes now; use Search Console's selected canonical evidence before choosing a preferred English version and changing redirects/sitemap/hreflang together.

These observations support correct crawl configuration. They do not establish that Google has indexed all 113 pages. Hreflang targets must remain reciprocal and consistent with canonicals. See [Google localized-page guidance](https://developers.google.com/search/docs/specialty/international/localized-versions).

## Structured data decisions

Existing homepage `WebSite`, `Organization` and `SoftwareApplication` were inspected before editing. Retained `https://capcar.dev/#website`, `/#organization`, and `/#application`. No new organization address, founder, reviews, social identities or capabilities were invented.

Article markup now uses `BlogPosting`, which fits visible editorial articles. Author/publisher reference the same named organization node, with logo and URL reused from the homepage. Each article has a canonical localized `#article` identity. Existing article update dates are preserved when supplied. No false update date or expert credential is added. See [Google Article guidance](https://developers.google.com/search/docs/appearance/structured-data/article).

The existing beta offer uses zero price because the visible beta FAQ supports it. Naming it “CapCar core garage beta” limits its scope. AI provider use is separately disclosed in visible copy. Software rich-result eligibility requires a real rating/review as well as the other required properties; none exists here, so no software rich result is claimed and no rating was fabricated. See [Google software application eligibility](https://developers.google.com/search/docs/appearance/structured-data/software-app).

`WebSite` remains useful for site identity. No fictional SearchAction, LocalBusiness, Product, Movie or FAQ schema was added to satisfy a checklist. The Movie Cars page describes car references rather than a complete film-review page. FAQ rich results were retired in May 2026; HowTo and the sitelinks search box are also retired appearances. See [Google supported-feature gallery](https://developers.google.com/search/docs/appearance/structured-data/search-gallery), [documentation updates](https://developers.google.com/search/updates), and [site-name guidance](https://developers.google.com/search/docs/appearance/site-names). Valid vocabulary does not guarantee rankings or appearance.
