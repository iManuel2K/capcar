# CapCar free directory submissions and tracking sheet

Researched 21–22 October 2026. **No accounts, forms, uploads, messages, purchases or submissions were performed.** Copy below is prepared for owner review. Approval to push repository work does not authorize these outward-facing actions.

Fifteen directory candidates were assessed. Five have a usable, currently evidenced free route worth preparing. This is a small consumer-software campaign, not a bulk backlink exercise. Founder-oriented directories have weaker owner fit than relevant car communities; cap this work at 1–2 hours per week. Directory traffic, search credit and rich results are not promised. No paid-only directory or irrelevant AI directory is in the submission queue.

## Existing Product Hunt and AlternativeTo work

The owner states both were previously worked on. Repository searches found no listing/submission records. Public exact-domain searches returned no confirming result; guessed `/products/capcar` and `/software/capcar/` pages could not be accessed by the research tool. These are **not verified listing URLs**, and missing search results do not prove there is no draft, pending or live listing. The owner confirmed no existing URL/status was available during this task.

Keep both on **hold: previously worked on, status unverified**. Before any future action, use the original account's submission dashboard and confirmation history to find the actual record. If live, inspect that listing; if pending, wait; if draft, update the same draft. Do not create another product, relaunch automatically, solicit votes or create comparison pages to justify a listing.

The public form requires an English, released product on its own domain; it discourages waitlists and agencies. Categories and real overlapping products help review. Domain-email verification helps management/priority. Authentication and later field requirements beyond the public first step were not completed. Evidence: [submission requirements](https://www.saashub.com/services/submit), [promotion process](https://www.saashub.com/product-promotion), [free promotion FAQ](https://www.saashub.com/faq). If any later step requires payment, stop and hold rather than pay.
- **Assets:** homepage/platform URL; short and longer descriptions; relevant categories; actual screenshots/logo; verified owner domain email if used. Competitor suggestions need current feature verification; a custom comparison page on CapCar is not required.
- **Additional free-route evidence:** SaaSHub's [own product-discovery listing](https://www.saashub.com/best-product-discovery-software/c/software-marketplace) explicitly describes free product submission; its [verification guide](https://www.saashub.com/site/product_verification) describes free verification. Featured promotion remains optional and paid.
- **Landing:** `https://capcar.dev/platform`.
- **Tagline:** “Car plans, maintenance records and costs together”.
- **Short description:** “CapCar is a digital garage for car owners who want to keep maintenance, parts, project plans and spending with the right vehicle. Explore public examples, then create an account to save a car and its next job. The core garage is free during beta.
