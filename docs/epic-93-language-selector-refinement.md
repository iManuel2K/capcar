# Epic 93 — Language selector refinement

The browser-native language dropdown has been replaced with a compact Capcar-owned popover.

- Compact surfaces show a translation icon and the active two-letter locale.
- Expanded surfaces show the active language name.
- The floating selector presents EN, DE, EL, SQ and JA as consistent segmented controls.
- The current locale has a clear selected state.
- The control supports keyboard focus, Escape-to-close, click-away dismissal and accessible menu semantics.
- The existing locale cookie and reload behavior remain unchanged.
