# Garage presentation assets

Transparent illustrative cutouts derived from the repository's existing showcase photos using the built-in image generation tool, October 19, 2026. Original photos remain unchanged. Never used in place of an owner-uploaded photo. These are presentation images, not evidence of vehicle specifications or modifications.

Sources: capcar-bmw-current-side.webp, capcar-project-f150.png, capcar-project-eclass.png, capcar-project-gti-tcr.png.

Shared generation prompt: "Use case: background-extraction. Edit target: the attached car photo. Create a clean transparent cutout of ONLY this exact whole car for an interactive website. Remove every background element, floor and reflection outside the car. Preserve this car's body shape, proportions, paint, wheels, trim, all windows and viewing angle. Keep the entire car, both bumpers, mirrors, tyres and roof fully visible with 8% clear margin. Do not create a scene, card, text, badges or gradient. Clean photorealistic edges, true transparent alpha background. Landscape canvas."

PNG outputs converted to 1100px WebP with alpha preserved. All assets referenced directly from this directory.
